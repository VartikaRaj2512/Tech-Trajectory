## 📌 Project Overview

**Tech-Trajectory** is an AI-powered Career Guidance System developed to assist students and aspiring professionals in making informed career decisions through intelligent recommendations. The system combines the capabilities of **Machine Learning** and **Web Development** to analyze users' technical skills, interests, and proficiency levels, and then predicts the most suitable career domain.

The project addresses one of the major challenges faced by students today: selecting an appropriate career path amidst rapidly evolving technologies and diverse job opportunities. By leveraging predictive analytics, the system provides personalized career recommendations and helps users identify the skills required to achieve their career goals.

---

## 🎯 Problem Statement

Choosing the right career path has become increasingly challenging due to the continuous expansion of technology-driven professions. Traditional career counseling methods often fail to provide personalized recommendations based on an individual's skills and interests.

This project aims to develop an intelligent web-based platform capable of predicting suitable career roles using Machine Learning while providing an interactive and user-friendly experience through Django.

## 🧠 Working Methodology

The system follows a structured Machine Learning pipeline:

1. User Registration & Authentication
2. Skill Assessment through Web Forms
3. Input Data Validation
4. Data Preprocessing
5. Feature Extraction
6. Career Prediction using a Trained Machine Learning Model
7. Result Generation
8. Personalized Career Recommendation Display

The trained prediction model is integrated into the Django backend using **Joblib**, enabling real-time career prediction with minimal response time.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/VartikaRaj2512/Tech-Trajectory.git
```

Move into the project directory

```bash
cd Tech-Trajectory
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the development server

```bash
python manage.py runserver
```

Open your browser

```
http://127.0.0.1:8000/
```
